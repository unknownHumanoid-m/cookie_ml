================================================================================
 split_bottleneck_ae — Architecture and Pipeline
================================================================================

OVERVIEW
--------
A joint model that replaces the SVD-based multi-stage pipeline
(denoise -> classify count -> per-count phase regressors) with a single
network trained on raw (16, 512) per-shot pulse images. One shared
2D-conv trunk feeds three heads: reconstruction (training only), pulse-
count classification, and phase regression (two heads, one per count).
Only the encoder + task branches ship on FPGA; the decoder is a training-
time artifact.

Input:   raw per-shot pulse image Ximg, shape (16, 512), from HDF5.
Targets: clean-truth Ypdf image (recon), integer npulses (count),
         phi0 rad in [0, 2*pi) (single-pulse phase), and
         arccos(cos(phi0 - phi1)) in [0, pi] (two-pulse phase).


================================================================================
 ARCHITECTURE
================================================================================

Shape flow (defaults: image (16, 512), encoder out 64 channels,
adapter_pool_len L = 24, bottleneck_count = 32, bottleneck_phase = 48):

    x  (N, 16, 512)                                 raw pulse image
      -> unsqueeze channel                          (N, 1, 16, 512)
      -> encoder (Conv2d stack)                     (N, 64, 18, 514)  = "feat"
           |
           +--(A) decoder (ConvTranspose2d stack) -> (N, 1, 16, 512)
           |         -> squeeze -> recon             (N, 16, 512)
           |         [training only; stripped at export]
           |
           +--(B) COUNT branch
           |         feat.mean(dim=(H,W))           -> (N, 64)         GAP
           |         Linear(64 -> 32)               -> z_count (N, 32)
           |         MLP [32 -> 64 -> num_classes]  -> count_logits
           |
           +--(C) PHASE branch (shared bottleneck for both phase heads)
                     TimeAdaptivePoolAdapter(feat):
                        feat.mean(dim=H)            -> (N, 64, 514)
                        adaptive_avg_pool1d(-> L)   -> (N, 64, 24)
                        flatten                     -> (N, 64*24 = 1536)
                     Linear(1536 -> 48)             -> z_phase (N, 48)
                     |
                     +-- MLP [48 -> 64 -> 2]        -> phase_single_out
                     |     (sin, cos) of phi0; decode via atan2 mod 2*pi
                     +-- MLP [48 -> 64 -> 1]        -> phase_two_out
                           scalar; decode via arccos(cos(.)) in [0, pi]

Encoder stack (mirrors src/denoising raw-AE so pretrained weights load):
    Conv2d(1  -> 16, k=3, pad=2) + ReLU
    Conv2d(16 -> 32, k=3, pad=1) + ReLU
    Conv2d(32 -> 64, k=3, pad=1) + ReLU
    -> feature map (N, 64, 18, 514)  (grows by 2 on H, W due to pad=2 in layer 0)

Decoder stack (mirror; sigmoid at the end):
    ConvTranspose2d(64 -> 32, k=3, pad=1) + ReLU
    ConvTranspose2d(32 -> 16, k=3, pad=1) + ReLU
    ConvTranspose2d(16 -> 1,  k=3, pad=2) + Sigmoid
    -> (N, 1, 16, 512)

Key design decisions
--------------------
* No recon-side bottleneck. `feat` feeds the decoder directly, so the
  pretrained raw-AE inverse holds from step zero.
* Count uses plain GAP (zero pool params). It does not need the time-axis
  structure, and paying the C*L flatten dim on FPGA for it would be waste.
* Phase uses TimeAdaptivePoolAdapter (row-mean, then adaptive_avg_pool1d
  along W to L bins). Keeps coarse "where along the pulse train" info for
  both phase heads while staying small (64*24 = 1536).
* Both phase heads share bottleneck_phase. The trunk learns one phase-
  relevant repr; the count classifier gates which head to trust on FPGA.
* Encoder/decoder key names match the raw-AE state_dict exactly
  (encoder.{0,2,4} and decoder.{0,2,4}) so pretrained weights load with no
  prefix surgery via `load_pretrained_denoiser`.

Deployed subgraph (InferenceSubgraph in model.py)
-------------------------------------------------
    encoder -> {GAP    -> bottleneck_count -> count_head,
                adapter -> bottleneck_phase -> phase_head_single,
                                             -> phase_head_two}

Decoder + recon path is dropped at export. TorchScript trace returns
(count_logits, phase_single_out, phase_two_out).


================================================================================
 PIPELINE
================================================================================

Files (all inside split_bottleneck_ae/):
    config.py             single source of truth for hyperparams / paths
    dataset.py            HDF5 loader (raw Ximg, Ypdf, npulses, phases)
    model.py              SplitBottleneckAE + InferenceSubgraph
    losses.py             recon MSE, CE count, sincos + arccos-cos phase,
                          Kendall & Gal uncertainty combiner
    train.py              warmup -> joint schedule, per-loss logging
    eval.py               metrics, confusion, phase scatters, JSON summary
    export_inference.py   strip decoder; save TorchScript + state_dict
    s3df_train.sh         SLURM launcher (ampere partition)
    s3df_eval.sh          SLURM launcher for eval
    figures/              training / eval figures land here

Stage 1 — Data ingest (dataset.py)
----------------------------------
    build_datasets(cfg.DATA, cfg.TRAIN_SAMPLES) -> (train_ds, val_ds)

    * `collect_h5_files` accepts a ":"-separated mix of .h5 files/dirs.
    * File-level (not shot-level) train/val split with a deterministic seed
      when DATA["val_dirs"] is empty; a separate val dir short-circuits it.
    * Per shot, PulseH5Dataset materializes into memory:
        - Ximg        -> (16, 512)  encoder input
        - Ypdf        -> (16, 512)  decoder target
        - npulses     -> label remapped to [0, K-1]; K = max-min+1;
                        top class = ">= max_pulses"
        - phases (fraction-of-turn):
            phi0 = phases[0] * 2*pi, wrapped into [0, 2*pi)
            dphi = arccos(cos(phi0 - phi1)) in [0, pi]  (2-pulse only)
            dphi = NaN                                    (n != 2)
    * Errors out if per-shot array shape != (16, 512) — guardrail against
      accidentally pointing at an SVD-compressed tree.

Stage 2 — Model construction (model.py)
---------------------------------------
    build_model_from_config(cfg) -> SplitBottleneckAE
    model.load_pretrained_denoiser(path)     # optional warm start

    * Encoder/decoder weights lifted from a trained raw-AE checkpoint
      (cfg.MODEL["pretrained_denoiser_path"]); task-branch params keep
      their fresh init.
    * All widths / pool_len / head hidden sizes come from cfg.MODEL.

Stage 3 — Training (train.py)
-----------------------------
    Two-phase schedule:

    (a) WARMUP  (cfg.TRAIN["warmup_epochs"] epochs)
        active_recon=True, active_task=False.
        Only encoder + decoder receive gradients. Reconstruction MSE only.

    (b) JOINT   (remaining cfg.TRAIN["epochs"] - warmup epochs)
        active_recon=True, active_task=True.
        All four losses live at once through the shared trunk.

    Per-batch forward (run_epoch):
        x, y_clean, count_label, phi0_rad, dphi -> device
        out = model(x, run_recon=..., run_task=...)
        total, parts = MultiTaskLoss(
            recon, recon_target,
            count_logits, count_label,
            phase_single_out, phi0_rad,
            phase_two_out, dphi,
            npulses_label, min_pulses,
            active_recon, active_task,
        )
        total.backward(); optimizer.step()

    Losses (losses.py):
        recon         = MSE(recon, Ypdf)
        count         = CrossEntropy(count_logits, count_label)
        phase_single  = MSE(phase_single_out, (sin phi0, cos phi0))
                        masked to shots with npulses == 1
        phase_two     = MSE(phase_two_out, dphi)
                        masked to shots with finite dphi (npulses == 2)

    Combiner: either static weights (w_recon, w_count, w_phase_single,
    w_phase_two) or Kendall & Gal uncertainty weighting with learnable
    log_var scalars per task (toggle via LOSSES["uncertainty_weighting"]).

    Logging: every epoch prints per-task losses on both train and val
    (weighted by valid-shot counts for the two phase heads separately, so
    sparse batches don't skew the average).

    Early stopping: on the joint val total; warmup epochs are skipped
    because their val total is entirely recon and is a different signal.

    Persistence at end of training (into cfg.IO["save_dir"]/run_name/):
        model.pth       = {state_dict, criterion_state, input_shape,
                           bottleneck dims, num_count_classes,
                           phase output dims, min/max_pulses, config snap}
        history.json    per-epoch metrics for both splits
        figures/training_curves_convae_<run>.png

Stage 4 — Evaluation (eval.py)
------------------------------
    python3 eval.py [--ckpt PATH]
    Defaults to IO["save_dir"]/IO["run_name"]/model.pth.

    Metrics on the test split:
        * recon MSE (mean over shots)
        * count accuracy + full KxK confusion matrix
        * single-pulse phi0 circular error (mean + median |err| in rad)
        * per-head phase MSE, ROUTED BY THE CLASSIFIER (not truth):
              - single scatter: only shots the classifier calls "1"
              - two scatter:    only shots the classifier calls "2",
                                AND whose true dphi is finite
          This mirrors the on-FPGA gate; the pipeline convention is
          "eval routes by the classifier, not by ground-truth npulses".

    Figures (into figures/, all keyed by run_name):
        eval_recon_convae_<run>.png             input vs recon vs truth
        eval_confusion_convae_<run>.png         row-normalized confusion
        eval_phase_scatter_single_convae_<run>.png
        eval_phase_scatter_two_convae_<run>.png

    Also writes eval_summary.json into the run dir.

================================================================================
 CONFIG KNOBS (config.py)
================================================================================

DATA
    train_dirs / val_dirs / test_dirs   ":"-separated .h5 files/dirs
    input_key = "Ximg"                  per-shot dataset fed to encoder
    target_key = "Ypdf"                 per-shot dataset for recon target
    image_shape = (16, 512)             enforced on load
    val_frac = 0.2, split_seed = 42     file-level split when val_dirs=""
    min_pulses = 1, max_pulses = 4      count-label range; top class means ">="

MODEL
    bottleneck_count = 32               feat GAP -> Linear width
    bottleneck_phase = 48               tapped -> Linear width (feeds BOTH phase heads)
    adapter_pool_len = 24               time-axis bins after adaptive_avg_pool1d
                                        (adapter output dim = 64 * L)
    count_head_hidden        = [64]     MLP hidden layers per head (list or [])
    phase_head_single_hidden = [64]
    phase_head_two_hidden    = [64]
    decoder_output_activation = "sigmoid"
    pretrained_denoiser_path = "..."    raw-AE .pth for encoder/decoder warm start

LOSSES
    w_recon / w_count / w_phase_single / w_phase_two   static weights
    uncertainty_weighting = False       swap in Kendall & Gal log_var scheme

TRAIN
    batch_size = 128, num_workers = 4
    warmup_epochs = 5, epochs = 60      recon-only warmup then joint
    lr = 5e-4                           Adam, single lr for both phases
    patience = 8                        early-stop on joint val total
    seed = 42

IO
    save_dir, run_name                  <save_dir>/<run_name>/ holds
                                        model.pth, history.json,
                                        eval_summary.json, inference/
    figures_dir                         pinned to ./figures/


================================================================================
 END-TO-END COMMAND SEQUENCE
================================================================================

    cd split_bottleneck_ae
    # (edit config.py paths, dims, weights as needed)
    python3 train.py                    # trains, snapshots best, writes
                                        # model.pth + history + figure
    python3 eval.py                     # metrics, confusion, phase scatters
    python3 export_inference.py         # drop decoder, TorchScript trace +
                                        # state_dict

Or via SLURM:
    sbatch s3df_train.sh
    sbatch s3df_eval.sh
